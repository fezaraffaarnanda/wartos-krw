# **Website Scraping Berita BPS Kabupaten Tegal**

Developed by Feza Raffa Arnanda dan Faqih Indra Lesmana

Fitur :
1. Scraping 4 portal berita untuk daerah Tegal (dan sekitarnya), yaitu radartegal, panturapost, kompas, dan tribunjateng.
2. Scraping berita setiap jam, user/admin tidak perlu klik tombol scraping. Apa yang tampil di dashboard adalah berita terbaru pada rentang jam tersebut.
3. Sorting menurut tanggal dan tag berita
4. Pencarian berdasarkan judul dan tag berita
5. Login admin dan user
