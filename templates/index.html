Petunjuk Pengguna

Langkah cepat untuk membaca tren dan insight dengan efektif.

  • Gunakan filter tanggal, KBLI, dan aktivitas ekonomi untuk fokus pada isu tertentu.
  • Buka detail berita dengan klik judul untuk membaca konteks lengkap.
  • Gunakan AI Insight dan AI Chat untuk ringkasan cepat sebelum analisis lanjutan.

Petunjuk Admin

Alur operasional untuk pengelolaan akun dan kualitas data scraping.

  • Gunakan menu Manajemen User untuk membuat akun dan generate password sementara.
  • Jika user lupa password, generate kode autentikasi (berlaku 1 jam, sekali pakai).
  • Lakukan scraping manual hanya saat dibutuhkan; sistem tetap scraping otomatis setiap jam.
